Hi, I'm Ashique. I build web applications that just work—smooth, fast, and scalable. My sweet spot is combining **Django** for reliable, high-performance backends with **Next.js** for clean, interactive frontends.

I thrive on creating apps that solve real problems without unnecessary complexity. On the backend, **Django REST Framework** keeps everything solid and scalable.

Take a look at my projects, explore the code, and if something resonates, let's connect. I'm always up for building something meaningful and impactful.
